### Lab: File path traversal, simple case
---
#### Objective: To solve the lab, retrieve the contents of the /etc/passwd file.
**Solving Steps**
Opening the lab page, I opened the developer console and looked at each image individually, where I found image HTML element with a parameter. Linking back to the reading content, this could be an attacking vector for path traversal, where I can modify the parameter to traverse and retrieve the content of the passwd file.  
- Open the image in a new tab, any image that uses a parameter works
- Modify the parameter, after filename to filename=../../etc/passwd
- Because no file is found, I kept on backtracking until the server responds with a 200 OK, ending up with filename=../../../etc/passwd
- Because the object is wrapped in img tags, I can view the response in the network tab where the response in given in HEX
- From here I used an online HEX decoder to decode the HEX to retrieve the passwd file
